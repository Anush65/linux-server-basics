Storage

Amazon S3

Private Object Storage

DeployGuard uses a private S3 bucket for application profile images and cloud assets.

Security

Public access is blocked and objects are protected using server-side encryption.

Versioning

S3 versioning is enabled to protect against accidental object replacement or deletion.

Database

Amazon RDS PostgreSQL

Application Metadata

Application names, developer information, repository URLs, types and deployment state are stored in PostgreSQL.

Private Database

The database is not publicly accessible. Access is restricted through the EC2 security group.

Backups

Automated RDS backups are enabled to support recovery from accidental data loss.

Security

AWS security controls

IAM Role

The EC2 instance uses an IAM role instead of storing AWS access keys inside the application.

Security Groups

EC2 traffic is restricted and the RDS database accepts connections only from the EC2 security group.

S3 Protection

S3 Block Public Access is enabled and the application accesses the bucket through IAM permissions.
